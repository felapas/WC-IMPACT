# Generated reporting artifacts

This directory contains aggregate tables and figures generated from the audited analysis outputs. They are useful for checking reported values and for alternative presentations.

The current edited FAME 2026 manuscript is **not** stored here. Its authoritative source is:

- `reports/submission_fame2026/main.tex`
- `reports/submission_fame2026/references.bib`
- `output/pdf/FAME2026.pdf`

Older generated DOCX/Markdown manuscript drafts are intentionally excluded from the public release to avoid ambiguity about which text is final.
