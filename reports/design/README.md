# Design diagnostics — Phase 4

Generated by `scripts/analysis/build_design_phase.py` from `config/analysis.yml` and `config/manual_design_overrides.csv`.

## Public aggregate outputs

| File | Content |
|---|---|
| `sample_flow.csv` | Cumulative cohort flow |
| `missingness.csv` | Missingness by population and treatment |
| `mde_power.csv` | Pre-treatment MDE/power diagnostics |
| `design_qa.csv` | Critical and informative QA checks |
| `national_team_support.csv` | Treated-control support by national-team eligibility |
| `design_data_dictionary.csv` | Design-variable metadata |
| `design_manifest.csv` | Row counts, hashes and lineage metadata |

Two row-level review outputs generated locally — `baseline_assignment_review.csv` and `national_eligibility_review.csv` — are intentionally excluded from the public release. The corresponding analytical datasets under `data/processed/` are also rebuilt locally rather than redistributed.
